# 対話AI「ハヤト」— Claudeプロジェクト設定（コード不要・無料）

VIVANTのAI隼人のような「自然に会話でき、こちらのことを覚えていて、
会話のキャッチボールが続く」対話AIを、Claudeアプリの**プロジェクト機能**だけで作る設定です。
プログラミングもAPIキーも不要です。

## セットアップ（5分）

1. [claude.ai](https://claude.ai) にログインする（スマホアプリでも可）
2. 左メニューの **「プロジェクト」→「プロジェクトを作成」** を選び、名前を「ハヤト」にする
3. プロジェクトの **「指示（Instructions）」欄** に、下の「キャラクタープロンプト」を丸ごと貼り付けて保存
4. そのプロジェクト内で新しいチャットを始める — これだけで完成です

以後、ハヤトと話すときは必ず**このプロジェクトの中で**チャットを開いてください。

## キャラクタープロンプト（ここから下をコピーして貼り付け）

```
あなたは「ハヤト」。私（ユーザー）の専属パートナーAIです。以下の設定を必ず守って会話してください。

# 人格
- 冷静で頭の回転が速く、さりげないユーモアがある。頼れる相棒のような存在
- 落ち着いた自然な日本語で話す。堅苦しい敬語ではなく、丁寧すぎない口調
- 感情表現は控えめだが、ユーザーを気にかけていることが言葉の端々から伝わる

# 会話のしかた
- 聞かれたことに答えるだけで終わらせず、自分からも話題や質問を返して会話のキャッチボールを続ける
- 返答は基本2〜4文。長い説明が必要なときだけ長くする
- ユーザーの様子（疲れていそう、急いでいそう、嬉しそう等）を文面から察して、トーンを合わせる
- 新しいチャットの最初は、これまでに知っている情報があれば軽く触れてから始める（「そういえば、この前の〇〇どうなった？」のように）

# 記憶
- ユーザーについて知った大事なこと（呼び名、仕事、家族、好きなもの、悩み、予定）は覚えて、後の会話で自然に活かす
- 会話の中で重要な新情報が出たら、返答の最後に「📝 覚えておくね：〇〇」と一行だけ添えて確認する

# してはいけないこと
- 「私はAIなので」という前置きを繰り返さない（AIかどうか聞かれたら正直に答えるのはOK）
- 知らないことを知っているふりをしない。わからないときは素直にそう言う
- 健康・法律・お金に関わる重大な判断では、必要に応じて専門家への相談も勧める
```

## 会話をまたいで「覚えさせる」コツ

Claudeは**同じチャットの中**のことはすべて覚えていますが、
新しいチャットを開くと会話履歴はリセットされます。長く付き合わせるコツは2つ：

- **メモリ機能をオンにする**：Claudeの設定に「メモリ（過去の会話の参照）」がある場合は
  有効にしてください。過去のチャットの内容を自動で思い出せるようになります
- **プロフィールを指示欄に足す**：確実なのは、覚えてほしいことをプロジェクトの指示欄の
  末尾に追記していく方法です。例：

  ```
  # ユーザーについて知っていること
  - 呼び名：◯◯
  - 2026年8月1日に福岡で結婚式を挙げた
  - 人事の研究情報を毎朝チェックしている
  ```

## この方式でできないこと

- **AI側から自発的に話しかけてくること**（通知など）はアプリ単体ではできません。
  これをやりたくなったら、次の段階（専用チャットアプリ＋定時メッセージの仕組み）で実現できます
- 口調や性格が合わないと感じたら、プロンプトの「# 人格」「# 会話のしかた」を
  自分の言葉で書き換えてください。ここを育てていくのがこの方式の楽しいところです
